# 👟 3D Shoe Viewer & Customizer

An interactive 3D shoe customizer built with modern web technologies, showcasing premium design, interactive animations, and smooth scroll.

## 🔗 Live Demo
Check out the live deployment on Vercel:
👉 **[Live Demo](https://work-1-main.vercel.app)**

## 🚀 Features
- **Interactive 3D Model**: Real-time rendering of a shoe model (`Shoe.glb`) using **Three.js**.
- **Cinematic Animations**: Smooth, high-performance scroll-driven and event-driven animations powered by **GSAP** (GreenSock Animation Platform).
- **Ultra-Smooth Scrolling**: Seamless, natural scrolling experience implemented with **Lenis**.
- **Vite Bundler**: Fast, lightweight development and build process.

## 🛠️ Technology Stack
- **Core**: HTML, CSS, JavaScript (Vanilla)
- **3D Graphics**: Three.js
- **Animations**: GSAP
- **Scroll**: Lenis Scroll
- **Bundler**: Vite

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/babarnaeem0001/task-1-threejs-shoe.git
   cd task-1-threejs-shoe
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
